# Personal Website

Space-themed personal site (aerospace) — plain HTML / CSS / JS, hosted on GitHub Pages.

## Files
| File | What it is |
|------|-----------|
| `index.html` | All the page content. Search for `EDIT` to find things to change. |
| `styles.css` | Colors & layout. Change the `:root` variables at the top to recolor. |
| `script.js` | Starfield animation, nav, scroll effects. Usually no need to touch. |
| `assets/` | Put `CV.pdf` and `profile.jpg` here (see `assets/README.txt`). |

## Edit locally
Just open `index.html` in a browser to preview. Edit files in any text editor and refresh.

## Publish updates (after first-time setup)
```bash
git add .
git commit -m "Update site"
git push
```
Your live site updates in ~1 minute at `https://<username>.github.io`.
