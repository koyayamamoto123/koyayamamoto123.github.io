PUT YOUR FILES HERE
===================

1. CV.pdf         → your CV/resume. The "Download CV" buttons link to this.
                    (Must be named exactly  CV.pdf )

2. profile.jpg    → a photo of you for the About section.
                    (Must be named exactly  profile.jpg  — square works best)
                    If you don't add one, a 🧑‍🚀 placeholder shows instead.

3. project images → optional. If you want real images on project cards instead
                    of the gradient + emoji, add them here and update index.html.

Tip: keep image files small (under ~500 KB) so the page loads fast.
