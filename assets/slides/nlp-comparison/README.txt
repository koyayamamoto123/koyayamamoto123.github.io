SLIDES FOR: "NLP Solver & Derivative-Accuracy Study"
====================================================

Save the slides here as slide-1.png, slide-2.png, slide-3.png, … (in order).
The website's "Slides ▸" button auto-detects however many are here.

EASIEST WAY (clipboard → file), from the Website folder:
  1. In PowerPoint, click the slide thumbnail (left panel) and press Ctrl+C.
  2. Run:   python add-slide.py "assets/slides/nlp-comparison"
     → it saves the next slide-N.png automatically.
  3. Repeat for each slide (copy → run).

(You can also right-click a slide thumbnail → "Save as Picture…" and save
